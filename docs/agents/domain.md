# Domain docs

## Before exploring

This repository uses a single-context layout.

- Read `GLOSSARY.md` at the repository root.
- Read decisions in `docs/adr/` relevant to the area being explored.

If these files are absent, proceed silently. The domain-modeling skill
creates them when terms or decisions are resolved.

## Vocabulary

Use the glossary's terms in issues, proposals, hypotheses, and test names.
If a needed concept is missing, reconsider the term or note the gap for
domain-modeling.

## Decisions

When a proposal contradicts an ADR, identify the ADR and explain why
its decision should be reconsidered.
